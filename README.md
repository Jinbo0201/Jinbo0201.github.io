# 个人主页（Personal Homepage）

基于 GitHub Pages 的个人学术主页，纯静态单页实现，无需构建工具。

在线访问：**https://jinbo0201.github.io/**

## 内容板块

页面自上而下包含以下板块（多数列表默认显示前 5 条，点击「显示更多」可展开其余条目）：

| 板块 | 说明 |
|---|---|
| 学习和工作经历 | 工作、博士后、博士、学士经历 |
| 出版物 | 期刊与会议论文（按时间倒序，带编号） |
| 专利 | 发明专利（带编号，附 Web / PDF 链接） |
| 软件著作权 | 软著清单 |
| 标准 | 参与编制的技术标准 |
| 课题 | 科研课题（起止时间 + 承担角色） |
| 工程项目 | 技术服务项目 |
| 获奖 | 竞赛奖项 |

## 目录结构

```
├── index.html      # 主页（HTML + CSS + JS 单文件）
└── files/          # 附件
    ├── publication/   # 论文 PDF
    ├── patents/       # 专利 PDF
    ├── softness/      # 软著 PDF
    └── standard/      # 标准 PDF
```

## 功能实现要点

- **列表折叠**：出版物 / 专利 / 课题 / 项目四个板块均默认展示最近 5 条，通过通用折叠组件（`.fold-panel` + `.more-btn`，配合 `aria-expanded` / `aria-controls`）展开或收起，展开数量由 DOM 自动统计；打印时自动全部展开并隐藏按钮。
- **自动编号**：出版物与专利列表使用 CSS `counter-reset` / `counter-increment` 自动编号，增删条目无需手动改号。
- **响应式**：适配移动端与打印样式。

## 如何更新

1. 编辑 `index.html`：在对应板块的列表中增删条目即可，编号与「显示更多 (N)」的数量均为自动计算。
2. 新增 PDF 附件：放入 `files/` 对应子目录（建议以完整标题命名），并在条目中添加 `<a href="files/...">PDF</a>` 链接。
3. 提交并推送到 `master` 分支，GitHub Pages 会在 1~2 分钟内自动部署上线。
